Claude at Excel: Write, Revise, Format & Analyse Data

Turning spreadsheets from a chore into a conversation

What it is

You describe what you want in plain English — "create a risk register for a satellite integration project" — and Claude writes the spreadsheet, formulas, conditional formatting, and summaries for you.

Why it matters

Engineers spend hours building spreadsheets from scratch. With AI, a complex requirements-traceability matrix or budget tracker is ready in minutes, already formatted and formula-checked.

What was done

Created structured data tables, wrote Excel formulas on demand, revised existing sheets for consistency, and produced automated summaries from raw datasets — all through conversation.

Step-by-Step Guide

1

Open Claude.ai (or the Claude Code CLI)

Go to claude.ai in any browser and sign in. No installation needed — it works like a chat window.

2

Describe your spreadsheet in plain English

Type what you need. Example: "Create an Excel table with columns: System ID, Requirement, Verification Method, Status. Pre-fill 5 example rows for a power subsystem."

Tip: The more context you give (project name, number of rows, column types), the more accurate the first result.
3

Ask for formulas or analysis

Follow up with: "Add a column that auto-colours rows red if Status = 'Fail', green if 'Pass'. Write the conditional formatting rule." Claude will give you the exact rule to paste into Excel.

4

Upload an existing spreadsheet for review

Click the paperclip icon, attach your .xlsx file, and ask: "Find inconsistencies in the budget column and suggest corrections." Claude reads the data and reports its findings.

5

Export and use

Claude returns clean tables you can paste directly into Excel or Google Sheets. For complex sheets, it can write a Python or VBA script that generates the file automatically.

Tip: Ask "now write a Python script that generates this file automatically" to create a repeatable, one-click solution.

Creating Presentations from Templates and Conversations

From a rough idea to a polished slide deck in minutes

What it is

Describe a presentation topic — or paste notes from a meeting — and Claude generates a fully structured slide outline, speaker notes, and content ready to drop into PowerPoint or Google Slides.

Why it matters

Presentation preparation typically takes hours. AI compresses that to minutes while maintaining professional structure: executive summary, technical detail, risks, and next steps — already in the right order.

What was done

Generated slide outlines from engineering review notes, adapted a company template to new project data, and produced speaker notes tailored to a non-technical executive audience.

Step-by-Step Guide

1

Give Claude the context

Start with: "I need a 10-slide presentation for a CDR (Critical Design Review). Audience: programme managers with no deep technical knowledge. Topic: integration status of the thermal control subsystem."

2

Provide raw material

Paste in your meeting notes, status updates, or bullet points. Claude transforms loose information into a logical narrative: problem → solution → evidence → risks → next steps.

Tip: Even badly formatted notes work. Claude will reorganise and tighten the language automatically.
3

Request a structured outline

Ask: "Give me the outline as: Slide number | Title | 3 bullet points | Speaker note." This format pastes neatly into PowerPoint's outline view.

4

Apply your company template

Upload your .pptx template and say: "Use this template's fonts and colours. Replace the placeholder text with the content above." Claude produces the updated text block-by-block.

5

Iterate on tone and depth

Say "make slide 3 less technical — the audience won't know what TRL means" and Claude rewrites just that slide. You never start from scratch again.

Cowork Space with Reusable Skills

Building a shared AI workspace your whole team can plug into

What it is

A "skill" is a saved, reusable instruction set — like a macro but for AI. You write the skill once ("always use our risk scoring scale", "always follow our document naming convention") and every future session applies it automatically.

Why it matters

Without reusable skills, every engineer has to re-explain company standards to the AI each time. Skills encode your team's knowledge once, so the AI always behaves like a trained team member.

What was done

Defined custom skills inside Claude Code for document formatting, risk categorisation, and status-report generation. These are now available to every team session automatically.

Step-by-Step Guide

1

Identify a recurring task

Think about something your team does repeatedly: writing a weekly status report, categorising defects, formatting meeting minutes. That is a candidate skill.

2

Write the skill as a CLAUDE.md file

In your project folder, create a file called CLAUDE.md. Inside, describe the rules Claude should always follow: tone, format, company terminology, and any standard templates to use.

Example entry: "When producing a risk register always use columns: ID, Description, Likelihood (1–5), Impact (1–5), Mitigation Owner."
3

Share the project with your team

Commit the CLAUDE.md to a shared Git repository (e.g. GitHub). Every team member who opens the project with Claude Code instantly has access to the same skills — no extra configuration needed.

4

Add custom slash commands

In .claude/commands/, add a file like weekly-report.md with a template prompt. Any team member can then type /weekly-report in the AI chat to generate a formatted report instantly.

5

Iterate and expand

As the team uses the skills, add new ones based on feedback. Skills evolve with your processes — they are living documents, not one-time setups.

Tip: Treat CLAUDE.md like an onboarding document. If a new hire needs to know it, the AI needs to know it too.

Agents Acting on Your Behalf: Web Research & LinkedIn

An AI that reads the internet and acts on professional platforms for you

What it is

An AI "agent" is Claude running a series of tasks autonomously: it can search the web for relevant news, summarise competitor activity, draft LinkedIn posts, and prepare outreach messages — all from a single high-level instruction.

Why it matters

Monitoring industry developments, preparing thought-leadership content, and maintaining a professional LinkedIn presence are high-value but time-consuming. An agent does the grunt work; you approve and publish.

What was done

Configured Claude Code with web-search capabilities to research industry topics, draft LinkedIn posts based on findings, and prepare personalised connection messages — ready for human review before sending.

Step-by-Step Guide

1

Enable web search in Claude Code

In the Claude Code settings, connect a web-search MCP (Model Context Protocol) server. This gives the agent the ability to read live internet data — news, job postings, company pages — on demand.

MCP is a standard connector: think of it like a plugin that gives the AI a new superpower. No coding required to enable it.
2

Define a research task

Tell the agent: "Search for the top 5 news items this week about model-based systems engineering. Summarise each in two sentences, note the source, and flag any items relevant to space programmes."

3

Ask it to draft LinkedIn content

Continue: "Now write a LinkedIn post sharing the most interesting finding. Tone: professional but accessible. Include a question to encourage comments. Keep it under 200 words."

4

Prepare outreach drafts

Ask: "Draft a connection request message for a systems engineering director at an aerospace firm I want to meet at a conference. Reference our shared interest in MBSE." The agent writes; you personalise and send.

5

Always review before publishing

The agent prepares; a human approves. This "human-in-the-loop" step ensures accuracy, tone, and compliance. The AI handles volume; you handle judgement.

Important: Never configure an agent to post or send without a human review step. Speed is not worth the risk of an unintended public message.

Chatbot Building with RAG and Local LLMs

An AI that knows your documents — and can run entirely on-premises

What is RAG?

RAG stands for Retrieval-Augmented Generation. Instead of the AI only knowing what it was trained on, you feed it your own documents (standards, manuals, procedures). It can then answer questions using your specific knowledge base.

What is a Local LLM?

A Local LLM is an AI model running on your own computer or server — not in the cloud. Your documents and queries never leave your network. Critical for sensitive or classified engineering data.

What was done

Built the architecture for a chatbot using Claude Code: a RAG pipeline that indexes internal documents, plus a local LLM option (via Ollama) for air-gapped or confidential environments.

Step-by-Step Guide: Build a Chatbot That Knows Your Documents

1

Gather your source documents

Collect the PDFs, Word files, or Confluence pages you want the chatbot to know about — engineering standards, process guides, lessons learned, ICD documents. Quality in = quality out.

2

Build the document index (the "retrieval" part of RAG)

Claude Code generates a Python script that reads your documents, breaks them into searchable chunks, and stores them in a vector database (like ChromaDB or Qdrant). This index is what the chatbot searches when you ask a question.

Tip: A vector database stores meaning, not just keywords. Asking "how do I handle a thermal anomaly?" will find the right procedure even if it says "thermal exceedance" in the document.
3

Choose your AI engine: Cloud or Local

Cloud option: use the Claude API — best quality, requires internet.
Local option: install Ollama and run a model like Llama 3 or Mistral on your own machine. Zero data leaves your network.

4

Build the chat interface

Claude Code creates a Streamlit or Gradio web interface. Engineers type questions in plain English; the chatbot searches the document index, pulls the relevant passages, and generates a precise answer with source references.

5

Test with real questions

Ask the chatbot questions your team actually has: "What is the approved torque value for M6 fasteners in the structural assembly?" or "What does procedure SE-0042 say about anomaly reporting timelines?"

If answers are wrong or incomplete, improve the document quality or chunking strategy — not the AI model. Garbage in, garbage out applies here too.
6

Deploy for the team

The chatbot runs as a web app on your internal server. Team members access it from a browser like any internal tool. No AI expertise needed to use it — just type and ask.
